# 完成前核验

用于在报告任务完成、测试通过或远端交付前核对相应事实。

## Codex 调用

显式调用 `$research-completion-verification`。

1. 把准备声称的结果与实际文件、相关测试或远端读回一一对应。
2. 优先使用本次已有且仍有效的验证，只为未解决的当前问题补查。
3. 分别说明实现、执行验证、远端交付和实际业务效果，不把其中一项代替其他项。
4. 缺少条件时标明 FAIL、BLOCKED 或 NOT_RUN；不以文字自称成功代替产物。
