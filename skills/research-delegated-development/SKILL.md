# 获准委派的开发

用于用户已授权子代理参与、且实施计划可以独立分工的开发。

## Codex 调用

显式调用 `$research-delegated-development`。

1. 先确认可用的子代理工具与工作区模型规则，为子任务明确输入、文件范围和验收标准。
2. 按实际依赖安排实现与审查，避免并发覆盖文件。相关提示文档可按需读取。
3. 父任务检查实际产物和相关验证后再整合，不只采信子代理自报完成。
4. 没有委派授权时按计划单线完成，不把此技能视为启动代理的额外授权。
