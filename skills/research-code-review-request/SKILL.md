# 代码审查请求

用于用户要求审查当前改动，或交付前需要核对具体风险时。

## Codex 调用

显式调用 `$research-code-review-request`。

1. 确定审查范围、比较基准及实际 diff，读取相关实现和验收要求。
2. 优先检查功能错误、范围偏离和已发生的回归风险，定位到实际文件与行号。
3. 在当前会话即可完成审查；调用其他代理需符合现有委派授权和环境条件。
4. 说明发现、依据和验证边界；不虚构 Task 工具或默认联系其他人员。
