# 并行任务委派

用于用户已经授权并行委派、且子任务彼此独立的工作。普通任务先单线执行。

## Codex 调用

显式调用 `$research-parallel-task-delegation`。

1. 确认当前环境实际提供子代理能力，并沿用工作区对模型、并发和文件归属的要求。
2. 仅拆分有明确输入、产物和边界的独立任务；避免多个执行者修改相同文件。
3. 向每个代理提供所需上下文和验收标准；等待结果后检查实际文件、差异和相关验证。
4. 工具不可用或没有委派授权时，说明条件并在已有授权内单线推进，不虚构代理消息或完成状态。
