# 实施计划编写

用于用户要求计划，或任务涉及多个有依赖的必要步骤时。

## Codex 调用

显式调用 `$research-implementation-planning`。

1. 读取相关代码或资料，整理目标、非目标、验收标准与不改动范围。
2. 列出完成本次任务的最小步骤及必要验证，路径和命令以仓库实际内容为准。
3. 信息足够时直接提出可执行方案，不要求用户自己设计提示词。
4. 只有需要交付计划文件时才落盘，不自动建立新框架、长期规则或后台任务。
