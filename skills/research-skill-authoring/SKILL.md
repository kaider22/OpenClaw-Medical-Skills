# 本仓库技能编写

用于创建或修改当前仓库的技能内容、名称与调用规则时。

## Codex 调用

显式调用 `$research-skill-authoring`。

1. 读取 ../../skill-authoring-standard.md，并检查实际任务、现有实现与支持资源。
2. 新技能目录、name 与 .agents/skills 入口同名；描述说明具体能力和触发情形。
3. 正文写明所需输入、真实执行方式、产物与失败条件；脚本、库、服务和纯指南分别说明。
4. 保留原版权及来源信息，命令只引用实际存在的资源，外部依赖缺失时如实标明。
5. 复用格式检查和本次必要的行为验证，不默认拉起多代理或建立新的测试体系。
