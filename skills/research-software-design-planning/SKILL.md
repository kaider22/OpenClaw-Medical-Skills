# 软件方案设计

把用户的软件想法整理为可实现、可验收的小方案。仅在任务需要设计取舍或用户要求方案讨论时使用。

## Codex 调用

显式调用 `$research-software-design-planning`。

1. 先读取当前任务涉及的代码或资料，复述目标、非目标、约束和完成标准。
2. 只询问会改变当前方案的缺失信息；已有明确授权和要求继续沿用。
3. 给出最小方案及必要的取舍，用户需要比较时再增加备选。方案明确后进入本次获准的实施范围。
4. 产物为简短方案和可观察的验收条件，不强制创建新项目、框架或审批流程。
