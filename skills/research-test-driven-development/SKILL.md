# 围绕当前行为的测试开发

用于用户要求测试先行，或当前行为变更需要新增最小回归验证时。

## Codex 调用

显式调用 `$research-test-driven-development`。

1. 先明确这次被接受的行为和可观察结果，检查现有验证能否覆盖。
2. 需要新增时先写一个主路径，必要时再加一个关键失败路径，并确认失败来自当前缺陷。
3. 做最小实现使其通过，仅在当前修改需要时重构。
4. 沿用项目测试工具；不补无关历史覆盖率，不用测试倒逼增加未要求的产品行为。
